# PowderLead · 粉体线索与样品管理系统

> 面向无机粉体材料企业的轻量化 B 端工具：统一管理展会客户线索、样品寄送台账与回访提醒，替代手工 Excel 台账。

## 项目背景

粉体材料（硅微粉、氧化铝、熔融石英等）是典型 B 端工业品生意：客户主要来自展会、线上询盘与老客户转介。一线业务日常大量依赖 Excel 和微信碎片记录展会线索、样品寄送与客户回访，存在**线索易丢、忘记回访、数据难统计**三个核心痛点。

PowderLead 聚焦"展会线索 + 样品管理"这一窄场景，用网页工具替代手工台账：登记即入库、状态可流转、超期自动提醒，帮助业务人员在展会高峰期不丢单、不漏跟。

> 本项目同时作为高校创新创业项目的真实落地案例：业务场景由企业提供，软件免费开发、非商用，仅用于学生课程 / 双创竞赛。

## 功能特性

- **经营看板**：线索总数、本月新增、样品在途、待回访事项一屏掌握；线索来源分布、产品咨询分布、状态漏斗实时图表
- **客户线索**：展会 / 线上线索统一登记（公司、联系人、电话、来源、产品、意向等级），按来源 / 产品 / 状态 / 关键词筛选搜索；跟进记录留痕，状态一键流转（新线索 → 跟进中 → 已寄样 → 已成交 / 已流失）
- **样品台账**：寄样登记自动生成编号（YP-2026-XXX），记录规格、数量、寄出日期、物流单号；状态点击流转（待寄出 → 已寄出 → 已签收 → 已回访），在途样品一目了然
- **回访提醒**：系统自动汇总逾期事项——新线索 ≥2 天未跟进、跟进中客户 ≥3 天无新进展、已寄出样品 ≥5 天未确认签收，点按钮直达跟进 / 处理
- **数据管理**：客户线索与样品台账分别导出 CSV（Excel 直接打开，中文不乱码）；JSON 备份一键导入导出，换设备可迁移

## 快速开始

1. 下载 `index.html`，双击用浏览器打开即可使用，无需安装任何环境
2. 首次打开内置 5 条演示客户线索与 2 条样品记录，可直接体验或删改
3. 所有数据保存在本机浏览器 `localStorage`，关闭页面不丢失

## 使用流程建议

```
展会结束 → 新增线索登记（来源/产品/意向）
    ↓
意向客户 → 寄样登记（自动编号 + 物流单号）
    ↓
样品寄出 → 状态流转：已寄出 → 已签收 → 已回访
    ↓
回访提醒 → 自动汇总逾期线索与在途样品 → 去跟进
    ↓
数据管理 → 定期导出 CSV / JSON 备份
```

## 数据与导出

| 项目 | 说明 |
|---|---|
| 存储位置 | 浏览器 localStorage（仅本机，不上传任何服务器） |
| 导出格式 | CSV（UTF-8 BOM，Excel 直接打开不乱码）+ JSON 备份 |
| 导出内容 | 客户线索表（公司/联系人/来源/产品/意向/需求/跟进）、样品台账（编号/规格/物流/状态） |
| 回访提醒规则 | 新线索 ≥2 天、跟进中 ≥3 天、寄出样品 ≥5 天（可调） |

## 技术栈

- 纯原生 HTML / CSS / JavaScript，单文件自包含
- 图表全部 Canvas 手绘（来源分布条形图 / 产品咨询饼图 / 状态漏斗），无第三方图表库
- 零外部 CDN 依赖，离线可运行
- 响应式适配：桌面侧边导航布局，移动端自动收窄，电脑手机都能用
